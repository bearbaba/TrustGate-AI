Security boundaries

The integrity digest by itself does not establish provenance. This lab validates an owner-signed intent, re-executes the current deterministic policy and checks current Concordium metadata. It does not establish historical server attestation, durable replay prevention, actual x402 payment, or security against an attacker who controls the verifier. For funds or private data, use a separately audited authorization and nonce store.
